# E-commerce Sales Analysis

## Objective

Analyze online retail transactions to understand sales performance, customer behavior, product performance, cancellations, and geographic trends.

## Main Business Questions

1. How much revenue did the business generate?
2. Which products generated the most revenue?
3. Which countries generated the most sales?
4. How did sales change over time?
5. Which customers generated the most revenue?
6. How much activity came from cancellations or returns?

## Final Deliverables

* Cleaned dataset
* Python cleaning script
* PostgreSQL database
* SQL analysis
* Power BI dashboard
* Business insights
* GitHub documentation
